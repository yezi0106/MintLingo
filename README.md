# MintLingo (背单词小程序)

MintLingo 是一款基于浏览器的纯前端单页面应用，致力于为您提供流畅、无广告、完全本地化的背单词体验。

## 🌟 核心亮点与技术架构

- **零后端依赖**：采用纯前端架构（Vue 3 + Tailwind CSS），数据完全依靠浏览器的 IndexedDB (借助 Dexie.js) 进行本地存储，注重您的隐私与数据安全。
- **SM-2 记忆算法**：内置经典的间隔重复算法，能根据您每次复习时的熟悉度，智能预测与排期下一次复习时间。
- **学习进度可视化**：提供基于学习记录的 GitHub 风格热力图、遗忘曲线预测图等数据统计。
- **定制化导入**：支持导入自定义格式的多类型本地词库（支持 `.txt`, `.csv`, `.json`）。
- **极速复习体验**：针对大批量积压单词专门优化，提供一键切换释义显示、单行/批量快捷“认识”按钮。

## 📖 使用指南

### 1. 如何运行
本项目无需复杂的环境及依赖配置：
1. 下载整个项目文件夹。
2. 直接使用现代浏览器（推荐 Chrome 或 Edge）双击打开 `index.html` 即可使用。

### 2. 如何导入词书
- 在侧边/顶部导航栏切换到 **“导入词书”** 面板。
- 上传您的词书文件，系统将自动解析为独立的词库供您切换学习。

### 3. 背单词与复习
- **今日计划**：可随时设定每日新词目标与学习模式，系统自动划定新旧词比例。
- **背单词卡片**：使用数字键 `1-4` 即可快捷标记单词掌握程度，系统会自动为您计划下一次碰面时间。
- **复习队列管理**：
  - 点击顶部的 **“隐藏释义”** 可将界面变为测试模式。
  - 对已熟悉的单词，点击绿色 **“✅”** 即可快速过词。
  - 勾选复选框，可一次性对大量单词进行 **“批量认识”** 标记。

### 4. 数据安全与备份
由于程序数据保存在浏览器本地（IndexedDB），清理浏览器缓存会导致数据丢失：
- 请务必定期前往 **“系统设置”** 面板点击 **“导出数据”**，将进度备份为本地文件。
